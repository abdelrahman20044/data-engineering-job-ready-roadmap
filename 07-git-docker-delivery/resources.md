# L07 Resources · Git, Docker & Delivery

## Recommended path

1. Learn Git Branching diagnostic and one recovery exercise.
2. Docker official getting-started material applied immediately to the flagship.
3. One GitHub Actions Python workflow—no platform tour.

## Arabic / Egyptian

- Kube-ops Git/Docker material — practical Arabic alternative when the exact lesson matches the task.
- TechWorld with Nana Docker explanations — clear visual supplement; official docs remain the behavior reference.

## English alternatives

- [GitHub Skills](https://skills.github.com/) — guided GitHub workflows.
- [Git from the Bottom Up](https://jwiegley.github.io/git-from-the-bottom-up/) — deeper mental model; later/reference.
- [Data Engineering Zoomcamp](https://github.com/DataTalksClub/data-engineering-zoomcamp) Docker material — one selected lab only.

## Practice / labs

- [Learn Git Branching](https://learngitbranching.js.org/)
- Dockerize the actual project rather than a hello-world app.
- Run a test workflow on a deliberately failing and then fixed commit.

## Reference

- [Pro Git](https://git-scm.com/book/en/v2)
- [Dockerfile reference](https://docs.docker.com/reference/dockerfile/)
- [Compose file reference](https://docs.docker.com/reference/compose-file/)
- [GitHub Actions documentation](https://docs.github.com/en/actions)

## Later / skip

- Later: image hardening, multi-platform builds and infrastructure as code.
- Skip Kubernetes, Terraform and complex CI/CD pipelines for the first portfolio project.
- Do not count an empty Dockerfile or workflow badge as evidence; another person must be able to run the system.
