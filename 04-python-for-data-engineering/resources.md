# L04 Resources · Python for Data Engineering

## Recommended path

Use the [Exercism Python track](https://exercism.org/tracks/python) as a diagnostic, then official documentation while restructuring one real script. This level is not a Python-from-zero course.

## Arabic / Egyptian

- Kiwilytics paid Arabic Python/Data Engineering material — consider only for a specific diagnosed gap after inspecting the syllabus.
- Arabic beginner playlists are not assigned because backend experience already covers programming fundamentals.

## English alternatives

- [Corey Schafer’s Python playlists](https://www.youtube.com/@coreyms) — select only the exact topic you cannot implement.
- [Real Python](https://realpython.com/) — supplementary explanations; watch for paywalls and publication age.
- [`uv` documentation](https://docs.astral.sh/uv/) — optional modern environment/dependency workflow.

## Practice

- [Exercism Python](https://exercism.org/tracks/python)
- Refactor a single-file API script into `src/` package, CLI and configuration modules.
- Add a context manager or generator where it materially improves resource use.

## Reference

- [Python 3 documentation](https://docs.python.org/3/)
- [Python Packaging User Guide](https://packaging.python.org/)
- [Psycopg 3 documentation](https://www.psycopg.org/psycopg3/docs/)

## Later / skip

- Later: Pydantic if project validation/config complexity justifies it.
- Skip: metaclasses, descriptor internals, async frameworks and broad web-development refreshers.
- Do not switch packaging tools repeatedly; one reproducible workflow is enough.
